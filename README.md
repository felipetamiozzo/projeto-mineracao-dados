# Student Performance — Data Mining Project

Projeto acadêmico desenvolvido na disciplina **Aplicação de Mineração de Dados**, do curso de Ciência de Dados da Universidade Cruzeiro do Sul.

## 1. Sobre o projeto

Este projeto tem como objetivo aplicar técnicas de mineração de dados e Machine Learning para explorar e investigar fatores associados ao desempenho acadêmico de estudantes.

A proposta envolve desde a extração e preparação dos dados até a construção, avaliação e disponibilização de um modelo preditivo.

## 2. Base de dados

**Student Performance Dataset**

- Fonte: UCI Machine Learning Repository
- Arquivo inicial: `student-mat.csv`
- Contexto: desempenho acadêmico de estudantes em matemática.

A documentação definitiva da base, seus atributos e condições de utilização será incorporada durante a análise dos dados.

## 3. Objetivos

- Realizar análise exploratória dos dados.
- Identificar padrões e possíveis relações entre variáveis.
- Preparar e transformar os dados para mineração.
- Desenvolver e avaliar modelos de Machine Learning.
- Interpretar os resultados e suas possíveis aplicações.
- Desenvolver uma interface para demonstrar a utilização do modelo.
